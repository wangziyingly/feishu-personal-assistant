# 飞书个人助手（Feishu Personal Assistant）

跑在你自己电脑上的飞书 AI 助手：科研文献、求职备战、日常助理三合一。
Python + 飞书官方 SDK 长连接（无需公网服务器）+ OpenAI 兼容大模型（Kimi / DeepSeek / OpenAI 均可）+ SQLite 本地存储。

## 功能总览

**📚 科研文献**

- 需求驱动搜文献：直接描述研究方向，自动扩展英文检索式、按相关性排序并附推荐理由（arXiv + Semantic Scholar，免费无需 key）
- 发 PDF 出结构化解读；「汇报第 N 篇 / 汇报 <标题>」生成组会级文献汇报（全文精读 + 批判性思考 + 问答准备）
- 本地文献库：标签管理、自然语言追问、重复内容缓存复用
- 每日论文订阅：按你的研究方向筛选 arXiv 新论文定时推送（时间/篇数可定制）

**💼 求职备战（五大板块）**

1. **岗位发现与匹配**：发 JD（粘贴/链接）→ 解析硬性要求/加分项/隐含偏好 → 结合简历打匹配分，给出投/不投/定制建议
2. **全网面经库**：面经链接/文本/**截图**发过来 → 提取题目 + 完整参考答案 → 按 产品类/算法类/Agent类 归档（本地题库 + 多维表格索引 + 知识库 20 题一篇分文档）
3. **面试准备**：JD 定制简历（ATS 对齐）、自我介绍/求职信、简历问诊（HR 视角挑毛病）
4. **模拟面试**：按 JD/简历/题库出题，多轮追问，STAR 复盘
5. **复盘与迭代**：实战错题 + 练习答砸自动进错题本，跨记录分析薄弱模式

**🤖 日常助理**

- 待办：自然语言创建、到点推送、每日早报
- 个人画像：记住研究方向/目标公司/简历要点，论文推荐和面试都按"你是谁"来做
- 多轮上下文：最近 10 轮对话滚动记忆，「新建对话」一键清空
- 图片理解：面经/JD/简历截图直接发（需要视觉模型，如 kimi-k3）

## 架构要点

- **意图路由**：LLM 意图分类（23 类，few-shot 驱动）+ 菜单裸指令硬编码表（确定的不交给模型）
- **成本漏斗**：检索后先做零成本硬过滤（去重/关键词/截断）→ 单次 LLM 批量排序 → 精读前查缓存，先便宜后贵
- **防虚构**：状态变更确认（已入库/已订阅）只由代码生成，闲聊 prompt 明确禁止声称完成动作
- **本地为主，云端为副本**：SQLite 是主存储；飞书多维表格/知识库是自动同步的索引与归档，同步失败不影响主流程

```
飞书消息 → 长连接 → 意图路由 → 模块（文献/面试/题库/岗位/待办/画像）
                        ↓                ↓
                  SQLite（主存储）   多维表格/知识库（索引与归档）
```

## 快速开始

### 一、飞书开放平台配置（一次性，约 5 分钟）

1. 打开 [飞书开放平台](https://open.feishu.cn/)，登录后进 **开发者后台**，点 **创建企业自建应用**（个人账号即可创建），填名称和图标。
2. 进入应用 → 左侧 **应用能力** → 添加 **机器人**。
3. 左侧 **权限管理**，搜索并开通：
   - `im:message`（获取与发送单聊、群组消息）
   - `im:message:send_as_bot`（以应用的身份发消息）
   - `im:resource`（获取消息中的资源文件，用于接收 PDF/图片）
4. 左侧 **事件订阅** → 订阅方式选择 **使用长连接接收事件** → 添加事件 **接收消息 `im.message.receive_v1`**（长连接无需公网回调地址）。
5. 左侧 **版本管理与发布** → **创建版本** → 申请发布。
6. 左侧 **凭证与基础信息**，复制 **App ID** 和 **App Secret**。

可选权限（用到再开）：`bitable:app`（多维表格归档）、`wiki:wiki:readonly` + `wiki:wiki`（知识库解析/归档）、`docx:document`（云文档写入）。改权限后需重新发布版本。

可选：在 **机器人 → 机器人自定义菜单** 配置聊天框上方的菜单（类型选"发送文字消息"，菜单名即发送的消息），本项目的菜单裸指令表见 `feishu_assistant/router.py` 的 `BARE_COMMANDS`。

### 二、本地安装与配置

```bash
git clone https://github.com/wangziyingly/feishu-personal-assistant.git
cd feishu-personal-assistant
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
cp config.example.yaml config.yaml   # 填入 App ID/Secret 和 LLM key
.venv/bin/python -m feishu_assistant.main
```

`config.yaml` 关键项：

- `feishu.app_id / app_secret`：上一步复制的凭证
- `llm`：任意 OpenAI 兼容接口。推荐 kimi-k3（多模态，可理解图片）；base_url / api_key / model 均可换
- `schedule`：待办早报、论文日报的默认推送时间
- `bitable` / `wiki`（可选）：多维表格与知识库归档，配置模板见 `config.example.yaml` 注释

## 常用指令速查

| 场景 | 说法 |
|---|---|
| 搜文献 | 「我在做多智能体信用分配，帮我找最新的方法」 |
| 文献汇报 | 「汇报第1篇」「汇报 Reflexion 这篇」（PDF 直接发） |
| 论文订阅 | 「订阅智能体方向的论文，每天早上九点推五篇」 |
| 录面经 | 「这篇面经帮我整理：…」或发面经截图 |
| 题库考试 | 「考考我」「考我算法类的题」 |
| 岗位匹配 | 「帮我看看这个 JD 适不适合我：…」 |
| 面试准备 | 「定制简历」「写个自我介绍」「简历问诊」 |
| 模拟面试 | 「模拟一场后端开发面试」「用题库模拟面试」 |
| 错题复盘 | 「今天面试被问到：…」「分析我的薄弱点」 |
| 待办 | 「明天下午3点提醒我交周报」 |
| 画像 | 「记住我的研究方向是多智能体」「个人画像」 |
| 上下文 | 「新建对话」（清空上下文重新开始） |

## 项目结构

```
feishu_assistant/
├── main.py          # 入口：长连接 + 定时任务
├── bot.py           # 飞书收发消息、文件/图片下载
├── router.py        # 意图路由（LLM 分类 + 裸指令表 + 滚动上下文）
├── llm.py           # OpenAI 兼容客户端（流式读取，防长生成超时）
├── db.py            # SQLite：用户/待办/文献/题库/错题/画像/订阅
├── scheduler.py     # 定时任务：待办提醒、早报、论文日报
├── bitable.py       # 飞书多维表格同步（题库/错题本/文献库索引）
├── wiki_kb.py       # 飞书知识库归档（面经库按分类分文档，20 题一篇）
└── modules/         # paper / interview / quiz / jobmatch / profile / todo
```
